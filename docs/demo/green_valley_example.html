Accounting definitions

Total modeled streamflow is groundwater exchange to the stream plus saturation excess. Daily depletion is unimpaired total streamflow minus pumped total streamflow. Reach-local values describe a reach and its incremental catchment; routed values include every connected upstream contribution. Reach accounting indicates where a flow change is received, not which well caused it.
